# Achievement Watcher Next 3.11.3

KytyPS5 trophies, an emulator identity for GBE Fork, separate sounds for rare, 100% and progress popups, a compact profile, a lighter background monitor and a round of fixes.

## Highlights

- **KytyPS5 trophies.** Games played on the KytyPS5 PlayStation 5 emulator are listed with their trophies, in your language when the game has it, with live notifications and Exophase rarity.
- **Emulator identity for GBE Fork.** Settings > Steam / GBE Fork (Advanced mode) sets the account name, Steam ID and save folder that the emulator fix and Repair write into each game.
- **A sound for rare unlocks, one for 100% and one for progress.** Settings > Notifications (Advanced mode). "None" silences that kind of popup, so progress popups can go quiet while unlocks keep their sound.
- **A compact profile and a calmer interface.** The profile folds into one row, on/off settings are switches, the game page fits more achievements, and the Theme tab is now Appearance.
- **PlayStation trophies keep their own colour**, platinum, gold, silver or bronze, in the popup and on the game page, and more console trophies get their unlock rate.
- **Lighter in the background.** The background monitor no longer restarts itself every hour, AW Next no longer keeps EA Desktop's whole log in memory, and the check for running games costs far less.
- **Fixes:** a game's very first unlock is notified, Steam games installed under Program Files get their playtime and "now playing" notification again, imported Xbox games stay in the library, Nemirtingas Epic games are tracked and notified, VOICES38 and RUNE releases are no longer taken for broken setups, screenshot souvenirs work for every source, and the installer no longer starts PowerShell.

See the [full changelog](https://github.com/Shirowwww/Achievement-Watcher-Next/blob/main/CHANGELOG.md#3113---2026-10-13) for the complete list.

## Install

| File | What it is |
|---|---|
| `Achievement.Watcher.Setup.3.11.3.exe` | The installer. An installed copy also updates itself. |
| `Achievement.Watcher.Portable.3.11.3.zip` | The same build with no installer: extract it anywhere, it keeps its settings, caches and logs in a `data` folder beside the executable. |
| `.blockmap` and `latest.yml` | Used by automatic updates, nothing to download by hand. |
