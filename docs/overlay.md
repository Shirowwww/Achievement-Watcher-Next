# In-game overlay list

Press `Ctrl+Shift+K` while a supported game runs to see its achievement list without leaving it:
names, descriptions, lock state, unlock dates and progress. Drag it by its header; it stays on top
of the game.

## What it shows

- A stats bar with `unlocked / total` and the completion percentage.
- A colored status pill, the unlock date once earned, and a progress bar for progress achievements.
- A rarity badge (`★ 12.3%`) when known: gold (≤5%), silver (≤10%), bronze (≤15%).

## Search and filters

Type to filter by name or description, or use the **All / Unlocked / Locked / In progress** pills.
Click **Rarity**, **Date** or **Status** to sort. Press `/` to focus the search box, `Esc` to clear it.

## Controller (gamepad)

Turn on **Control the in-game overlay with a controller** in **Settings → Controller** to open,
navigate and scroll the list with a gamepad. See the [controller guide](controller.md) for the
button layout, supported pads and a Windows caveat about the game still seeing your input.

## Customization

Open the **⚙** button in the header. Changes apply immediately and are saved locally; **Reset
defaults** restores the original look.

| Option | Values |
|---|---|
| Accent | 5 color presets, a custom picker, or **Use app theme** |
| Density | Compact, Cozy, Spacious |
| Icon size | Small, Medium, Large |
| Zoom | 80% to 125% |
| Opacity | 40% to 100% |
| Show/hide | Stats bar, progress bars, rarity badges, descriptions |

## Keyboard shortcuts (overlay open)

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+Shift+Arrows` | Nudge the overlay window |
| `Ctrl+Alt+Shift+1` ... `5` | Snap to a preset position |
| `Ctrl+Alt+Shift+C` | Toggle click-through |
