What it does

One library

Every enabled source in one list, with unlock history, rarity tiers, progress achievements and cover art. Six views, from large cards to a dense table, and all of it cached so it opens offline.

Game Health, built for cracked games

Made above all for cracked and emulated games: their achievements live in their own files, a Steam emulator's save (Goldberg, GBE Fork, CODEX, RUNE, CPY…), an emulator's folder, a Uplay R1 or R2 config, and AW Next reads them there, offline. When one does not show up, Game Health checks the game, says Ready, Needs attention or Not tracking with the reason in plain words, and offers the one repair that fits, confirmed first and backed up.

The moment, on video or in a shot

Like a console's trophy video: the last seconds of play stay in memory, encoded by the graphics card, and the stretch around each unlock is saved as an MP4 with the popup in it. Or a screenshot a moment after the unlock, tone-mapped to a clean PNG even with Windows HDR on.

Your library, in figures

Overall completion, perfect games, unlocked and locked counts, the average per game, your trophies by grade and your rarest unlocks, with a row per platform. One click from the profile header.

Where it reads from

Each source is a switch in Settings. Achievement lists come from public endpoints and are cached on disk, so there is no Steam Web API key to paste anywhere.

Steam Installed games, plus your whole account library and unlocks from your other PCs once connected
Cracked games (Steam emulators) Games cracked with Goldberg, GBE Fork, CODEX, RUNE, CPY, GreenLuma, SmartSteamEmu, CreamAPI or Nemirtingas, read from their own saves
GOG Galaxy The local Galaxy databases, and compatible legacy saves
Epic Games Installed or owned games, with unlock state after an optional account connection
Ubisoft Connect Local data, legacy Uplay formats, and compatible Uplay R2 setups
EA Desktop The local achievement log, for installs outside EA's managed folders
Emulators RPCS3, ShadPS4, KytyPS5, Xenia and Xbox 360 games recompiled for PC, watched live
Xbox PC Game Pass and Microsoft Store installs, plus imported Xbox Network state
RetroAchievements Every game you played on an emulator that reports to your account, with unlocks announced within seconds

Reading achievements never writes anything. The emulator repair tools do change game files, after a confirmation and with a backup. Use them only with games you own.

Make your own

Settings has a designer for layout, type, colours, motion, the rare and 100% treatments and a sound. No CSS, no JSON, and the preview is the real popup. Start from a ready-made style or press Surprise me.

Make your own

Settings, Theme, Custom opens an editor over nine layers, from the window to the accent. Each takes a colour, an opacity and a background image, and the app repaints as you drag.

Trophy mode

Grade every achievement gold, silver or bronze by how rare it is, with platinum for a finished game.

Overlay or notification

On Automatic, each unlock goes where you can see it: the overlay while you play, a desktop notification in exclusive fullscreen or when the overlay fails. Never both at once.

The full list, in game

Ctrl+Shift+K brings the running game's achievements up over it, with search, filters, rarity badges and hidden descriptions on demand. A gamepad drives it too.

Collections

Getting it running

  1. Install it

    Windows 10 · 11

    Achievement.Watcher.Setup.<version>.exe from the releases page, or Achievement.Watcher.Portable.<version>.zip if you would rather have no installer: extract it anywhere and its data stays beside it. Nowhere else publishes them.

    Settings and data: %APPDATA%\Achievement Watcher Next

    Download for Windows

    Linux AppImage, beta

    Achievement.Watcher.<version>.AppImage from the same page: make it executable and start it. It needs FUSE 2 (libfuse2), updates itself and watches the games you run through Steam, Proton, Wine, Lutris, Heroic or Bottles. The Linux guide covers desktops, the overlay shortcut and the Steam Deck.

    Settings and data: ~/.config/Achievement Watcher Next

    Download for Linux
  2. Run Smart Find Settings, then Folders. Add any game or save folder it could not guess.
  3. Leave it in the tray That is the watcher. Live notifications and playtime depend on it running.
