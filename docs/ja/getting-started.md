# はじめに

AW Next は Windows と Linux 用のデスクトップアプリです。リリースには専用のランタイムが含まれているため、Node.js が必要なのはソースからビルドするときだけです。Linux では、[Linux と Steam Deck](linux.md) の説明に従って AppImage をインストールしてから、このページに戻ってください。以下はすべて Linux にも当てはまり、`%APPDATA%\Achievement Watcher Next` は `~/.config/Achievement Watcher Next` に読み替えます。

## インストール {#install}

| 手順 | Windows 10 と 11 | Linux (x64、ベータ) |
|---|---|---|
| **入手** | [最新リリース](https://github.com/Shirowwww/Achievement-Watcher-Next/releases/latest)から `Achievement.Watcher.Setup.<version>.exe`。データをアプリの隣に置くなら `Achievement.Watcher.Portable.<version>.zip` | 同じリリースから `Achievement.Watcher.<version>.AppImage` |
| **起動** | インストーラーを実行してフォルダーを選び、スタートメニューから AW Next を開く | `chmod +x` してから実行。FUSE 2 が必要で、Ubuntu 24.04 では `libfuse2t64` |
| **データ** | `%APPDATA%\Achievement Watcher Next` (ポータブル版は実行ファイルの隣の `data` フォルダー) | `~/.config/Achievement Watcher Next` |

> [!WARNING]
> インストーラーはプロジェクト独自の自己署名証明書 (`CN=Shirow`) で署名されているため、Windows
> SmartScreen が確認を求めることがあります。
> [ウイルス対策ソフトまたは SmartScreen の警告](troubleshooting.md#antivirus-or-smartscreen-warning)を参照してください。アプリ内
> アップデートは、この証明書で署名され、拇印で固定されたリリースだけをインストールします。

初回ガイドでは、ライブラリを作るための選択を尋ねます。

- **基本**：言語(インターフェース、およびソースが対応している場合はゲームのメタデータ)と、インターフェース
  (シンプルか詳細か。後述)。どちらも最初は選ばれていません。
- **プロフィール**：ヘッダーに表示する名前、任意のローカルアバター、メインの Steam アカウント。
- **ゲーム**：このPCで見つかったものと件数。足りないものがあるときだけフォルダーを追加します。
- **ソース**：任意のサインイン(Steam、Epic、Xbox、PlayStation、RetroAchievements)。実際のライブラリや、別のPCで行った解除を読み取ります。
  省略して、あとから **設定 → ソース** で接続できます。ソースごとのスイッチはすべて **ソースを微調整** にあり、
  既定値でインストール済みのものはすべて読み取られるため、折りたたまれています。
- **外観と通知**：テーマと、解除の知らせ方。**通知をテスト** ボタンがあります。
  既定の **自動** なら、何も決める必要はありません。
- **準備完了**：各選択の **変更** ボタンが付いた確認画面と、コレクション、トロフィーモード、ビデオクリップ、
  オーバーレイへの案内。

## シンプルと詳細 {#simple-and-advanced}

初回ガイドで選び、あとからは **設定** の上部にある **インターフェース** のコントロールでいつでも変更できます。

<div align="center">
<picture><source srcset="../assets/shot/settings-panel-800.webp 800w, ../assets/shot/settings-panel.webp 940w" sizes="(max-width: 700px) 100vw, 720px"><img src="../screenshot/settings-panel.png" width="720" height="529" alt="AW Next の設定" loading="lazy" decoding="async"></picture><br>
<sub>インターフェースのコントロールはパネルのタイトルの横にあり、検索欄はすべてのタブを一度に絞り込みます</sub>
</div>

- **シンプル** は日常で使うタブを表示します：一般、外観、コントローラー、通知、通知プリセット、ソース、フォルダー、ヘルプ。
- **詳細** は **Steam / GBE Fork**、**Ubisoft / Uplay R1/R2**、**詳細** のタブと、ほかのタブの中の
  より踏み込んだオプションを追加します。

**シンプルはコントロールを隠すだけで、何もオフにしません。** 追跡、スキャン、通知の動作は同じで、設定した値は
切り替えて戻してもそのまま残ります。ゲームの状態も同じ考え方です。シンプルでは *実績データが見つかりました* や
*ゲームの起動時に検出されます* と表示され、詳細では正確な件数、ファイル、プロセス名が表示されます。既存のインストールは
**詳細** にアップグレードされるので、使っていたものが消えることはありません。

**設定** の上部にある検索欄はすべてのタブを一度に絞り込み、タブごとに一致の件数を数えます。
ラベル、説明、オプションの値、内部名を検索するので、`hideZero` はどの言語でも同じ行に一致します。
`Ctrl+F` で検索欄に移動し、`Esc` で消去します。

## ライブラリ {#the-library}

**設定 → ソース** では、盾のマークが公式のデスクトップライブラリを示します。行を有効にして更新すると、
このPCで検出されたライブラリだけが表示されます。[対応ソース](sources.md)を参照してください。

ライブラリの検索欄と `+` ボタンの間にあるセレクターで、6 つの表示を切り替えます。大きなカード、
縦長カバー、その 2 つのコンパクト版、リスト、そしてプレイ時間と最後のセッションを載せた詳細テーブルです。選択は保存され、
どの表示でもカード、フィルター、コンテキストメニューは同じです。

プラットフォームのアイコン、状態の点、2 つのボタンの表示と非表示を、すべての表示にまとめて適用できます。
Steam に載っていても実績のないゲームは、バーの代わりにアートワークを表示します。**実績のないゲームのバー** で

ゲームを右クリックすると、名前の変更、プレイ時間の編集、コレクションへの追加ができます。設定した名前は
再スキャンや復元のあとも残り、カバーやマッチングには元のタイトルが使われます。Steam のゲームは、実績の言語
(**設定 → 一般**)でタイトルを表示できます。

### ライブラリの統計 {#library-stats}

プロフィールヘッダーの達成率の隣にある丸いボタンで **ライブラリの統計** が開きます。全体の達成率、解除済みと未解除の数、
ゲームあたりの平均、平均と記録されたプレイ時間、トロフィーの数、そしてプラットフォームごとの 1 行です。

## テーマ {#themes}

**設定 → 外観** で、アプリ全体とゲーム内オーバーレイの色を決めます。13 種類のパレットが内蔵されており、
どれも編集できます。テーマを選ぶとエディターがその色で開き、レイヤーごとに 1 行あります(ウィンドウの
背景、トップバー、ライブラリパネル、カードと行、設定ウィンドウ、テキスト、控えめなテキスト、枠線、アクセント)。
各レイヤーには不透明度つきの色と、必要ならグラデーションを指定でき、5 つの面のレイヤーには、
フィット方法を選んだ背景画像と、色付きのベールまたはぼかしも指定できます。

編集はリアルタイムでプレビューされ、何も書き込みません。**テーマを保存** で自分のテーマになります。名前をそのままにすると
そのテーマを置き換え、別の名前を入力すると 2 つ目のテーマになります。**カスタム…** は下書き用のスロットで、
常に編集でき、そこから保存しても上書きされません。**すべてリセット** は編集中のテーマを元に戻します。
内蔵テーマは自身のパレットに、保存またはインポートしたテーマはディスク上の内容に、カスタムは既定のパレットに戻ります。

**テーマファイル** は、テーマを持ち運べる 1 つのファイルにします。**テーマをエクスポート…** は、使ったパレット、
グラデーション、エフェクト、画像を含む `.awtheme` を書き出し、お使いのPCに関する情報は含めません(画像はパスではなく
バイトとして格納されます)。内蔵テーマのエクスポートは、自分の名前で保存するまで拒否されます。そうしないと、ファイルがほかの環境で
「Nord」としてインストールされ、すでにある Nord を覆い隠してしまうためです。**テーマをインポート…** は、まずそのテーマで描画した
アプリを、名前、作者、バージョン、画像の数とともに表示し、確認したときだけインストールします。**テーマを削除** は、
インポートしたテーマを画像ごと削除します。

`.awtheme` に入っているのは色、数値、画像だけなので、何かを実行したりネットワークにアクセスしたりすることはできません
([形式のリファレンス](../awtheme-format.md)を参照)。ほかの人が作ったテーマは
[テーマギャラリー](../gallery/themes/)にあり、自分のテーマの投稿は[ファイル 1 つ](community-galleries.md)でできます。
`*.css` ファイルを `%APPDATA%\Achievement Watcher Next\themes` に置くと、これまでどおり一覧に表示されますが、
エクスポートはできません。

## ヘルプとヒント {#help-and-tips}

**設定 → ヘルプ** は、疑問の出方ごとにまとめられたリアルタイムのリファレンスです：**はじめに**、
**うまく動かないとき**、**エミュレーターのゲーム**、**カスタマイズ**。実際のホットキー、コントローラーの
配置と割り当て、テーマ、通知モードが表示され、設定を変えると更新されます。検索は大文字小文字とアクセントを区別せず、
どのトピックもどちらのインターフェースモードでも利用できます。

## ゲームとセーブデータを探す {#find-games-and-saves}

**設定 → フォルダー** を開いて、パスを選びます。

- **スマート検索** は、見つけたものをすべて提示し、承認を得てから追加します。ライブラリのフォルダーを名前で認識し
  (「Games」「Jeux」「Repacks」と、二十数言語でのそれらに相当する名前、さらに
  「Emulators」と「Emulation」)、すべてのドライブを対象にします。また、ランチャーが記録した情報も読み取ります：Epic の
  マニフェスト、GOG Galaxy と Ubisoft Connect のレジストリエントリ、Xbox のゲーム用に選んだドライブに Windows が書き込む
  ポインターです。これで、ストア名のついたライブラリ(`D:\Epic Games`、`D:\XboxGames`)がスキャンなしで見つかります。
  ランチャーが管理するゲームは、それぞれのソースのままです。スマート検索は、同じフォルダーにあるそれ以外をすべて追加します。
  リパックや Goldberg ビルドが置かれるのは、たいていそこです。
- **フォルダーを追加** は、選んだ場所を監視します。
- **設定を生成** は、より詳しいスキャンを実行し、有効なエミュレーターのセットアップオプションを適用できます。

フォルダーが拒否されたら、セーブフォルダー、AppID フォルダー、`steam_settings`、またはエミュレーターの設定を
直接含むディレクトリを選んでください。[トラブルシューティング](troubleshooting.md#a-game-is-missing)に
最初の確認事項があります。フォルダー名が複数の Steam リリースに一致して誤っている場合は、
ゲームを右クリックして **AppID を手動で設定…** を選びます
([ゲームの AppID を手動で設定する](advanced.md#set-a-games-appid-by-hand)を参照)。

実績リストに Steam Web API キーは不要です。公開エンドポイントから取得して言語ごとにキャッシュするため、そのあとは
オフラインでもライブラリが動作します([仕組み](sources.md#steam-metadata-without-an-api-key))。

## 通知 {#notifications}

**設定 → 通知** で配信モードを設定します：**自動**(既定。表示できるときはゲーム内オーバーレイ、できないときは Windows
またはデスクトップの通知で、同じ解除を 2 回知らせることはありません)、**ゲーム内オーバーレイ**、**Windows 通知**、
**両方**。Windows の応答不可でプレイ中に通知が隠れる場合は、**優先度の高い通知** を有効にして、
一度だけの確認を承認してください。テストボタンで、ゲームを起動する前にすべてを試せます。[通知](notifications.md)と
[自動の判断基準](notifications.md#how-automatic-decides)を参照してください。

## ゲームを確認する {#check-on-a-game}

ゲームのタイルにある **ツール** ボタンで **ゲームの状態** パネルが開きます。AW Next がそのゲームを認識しているか、
実績を読み取れているか、解除を通知できるか、そして適用できる修復が分かります。問題を報告する前に
最初に開くものです([ゲームの状態](game-health.md)を参照)。ゲームを最初からやり直すには、
[実績のリセット](advanced.md#reset-a-games-achievements)を使います。事前にすべてをバックアップします。

## トレイとスタートアップ {#tray-and-startup}

メインウィンドウを閉じても AW Next はシステムトレイに残り、バックグラウンドのトラッカーがプレイ時間と解除のために
ファイルとプロセスを監視し続けます。ウィンドウが開いていないときはメモリを Windows に返し、定期的なライブラリのスキャンは
ゲームの実行中は待機します。**設定 → 詳細 → 実績データの自動更新** で、`steam_cache` を手動で管理している人向けに
このスキャンをオフにできます。AW Next を Windows と一緒に起動するか、閉じたときにトレイに入れるかは
**設定 → 一般** で設定します。完全に終了するには、トレイメニューを使います。

## アップデートと既存のデータ {#updates-and-existing-data}

インストール版は、プロジェクトの GitHub リリースフィードを確認します。ゲーム中には確認しません。新しいバージョンは
デスクトップ通知とタイトルバーのチップ(トレイアイコンにも青い点が付きます)でお知らせし、ゲームやほかのアプリから
フォーカスを奪うことはありません。お知らせは閉じるまで残り、ゲームのあとにまた表示されます。

通知かチップをクリックするとアップデートウィンドウが開きます。スキップしたすべてのバージョンのリリースノートと
ダウンロードサイズが表示され、**今すぐアップデート**、**後で**、**このバージョンをスキップ** を選べます。
選ぶまでは何もダウンロードされません。**今すぐアップデート** を選ぶと、同じウィンドウでダウンロードの進行を確認でき、
キャンセルやバックグラウンドへの移動もできます。タイトルバーのチップが状態を示し、ウィンドウを呼び戻します。
ダウンロードが終わると、インストーラーが専用の進捗カードを表示し、AW Next が再起動します。ゲームが実行中の場合は、
終了するまでインストールが待機します。ウィンドウから、そのままインストールすることもできます。**設定 →
更新を確認** でウィンドウがすぐに開きます。アップデートは変更された部分だけをダウンロードし、失敗すると自動的に
完全なインストーラーに切り替わります。Linux の AppImage も同じリリースからアップデートされます
([Linux のアップデート](linux.md#updates)を参照)。

古いビルドの上に新しいビルドをインストールしても、データは `%APPDATA%\Achievement Watcher Next` に残ります：
設定、監視フォルダー、キャッシュ、プレイ時間、ログ、通知のアセット、ローカルのアカウントデータです。
アップグレード後の最初の起動で、AW Next は以前のインストールを取り込みます。

| 移行元 | 取り込み元 | 動作 |
|---|---|---|
| Achievement Watcher 3.x | `%APPDATA%\Achievement Watcher 3.0` | 設定、プリセット、テーマ、カバー、キャッシュ、バックアップ、ログが引き継がれる |
| Achievement Watcher 1.6.8 | `%APPDATA%\Achievement Watcher` | 同じ。3.x を飛ばした人向け |
| 新しいマシン | なし | AW Next は既定値で起動する |

取り込みは一度だけ実行され、小さなファイルはコピーし、一度しか書き込まれない大きなファイルはハードリンクし、
**読み取り元のフォルダーを削除したり変更したりすることは決してありません**。レジストリに保存されたプレイ時間のカウンターも
引き継がれ、スクリーンショットは、独自のフォルダーを選んでいない限り `Pictures\Achievement Watcher Next` に移ります。

アンインストールでは、既定でオフのオプションが 1 つ表示されます：**設定、キャッシュ、保存データも削除する**
(サイレントアンインストールでは `--delete-app-data`)で、データフォルダーとレジストリのプレイ時間を削除します。
アップデートが同じダウンロード済みファイルで失敗し続ける場合は、**設定 → 詳細 → キャッシュを消去** で、
再ダウンロードできるキャッシュ(アップデートのファイル、Steam と Ubisoft のスキーマとアイコン、エミュレーター修復ツール)だけが削除されます。
設定、セーブ、バックアップは残ります。
