# コミュニティギャラリー

2 つのギャラリー、1 つのサービス、1 つのルールです。

| | | |
|---|---|---|
| [プリセットギャラリー](../gallery/) | `.awpreset` | 通知のポップアップ：レイアウト、書体、色、動き、サウンド |
| [テーマギャラリー](../gallery/themes/) | `.awtheme` | アプリのそれ以外の部分：ウィンドウ、タイトルバー、ライブラリ、実績リスト、設定、オーバーレイ |

どちらからでもダウンロードするには、ファイルを入手して、**設定 → 通知プリセット → インポート** または
**設定 → 外観 → インポート** を使います。このページでは、その反対側を扱います。追加する方法、何が確認されるか、
そしてカードに何を書けるかです。

## 送信する {#sending-one}

流れは両方とも同じで、**公開** を押すまで、何もブラウザーの外に出ません。

1. **エクスポートする。** プリセットなら 設定 → 通知プリセット → エクスポート、テーマなら 設定 → 外観 →
   エクスポートを使います。ファイルには、名前、説明、バージョン、タグ、そして必要な AW Next のバージョンが
   すでに含まれています。
2. ギャラリーのページの *あなたの作品を送る* パネルで**ファイルを選ぶ**か、パネルにドロップします。選んでも
   何も送信されません。残りを入力する間ファイルは待機し、パネルにはその内容が示されます。
3. **カードに何を表示するか確認する。** ファイルを選ぶとすぐに、パッケージから 4 つの欄が埋まります：
   **名前**、1 行の**説明**、**タグ**、**クレジット**です。クレジットはエクスポート時にアプリが記録した
   作者、つまりあなたが名乗っている名前で、クレジットを付けないことを選んだ場合にだけ空になります。タグを入力して
   Enter を押すとチップになり、チップをクリックすると取り除かれます。

   **名前は、必ず入力しなければならない唯一の欄です。** カードの見出しになり、ファイルが公開されるアドレスの元になり、
   他人のために選ばれた名前は、結局モデレーターが書き直すことになります。
   名前がないと、公開ボタンは反応しません。残りの 3 つは空でもよく、その場合、カードにはそこに何も表示されません。
4. **公開を押す。** 画像は推測ではなく描画されるため、数秒かかります。そのあとは
   待機です：メンテナーが承認するまで、ギャラリーには何も表示されません。

これらの欄にあるものはすべて**提案**です。入力されている場合にだけパッケージを上書きし、マニフェストとまったく同じように
クリーニングされ、何かが公開される前に、メンテナーが描画された画像の隣で 4 つすべてを確認します。
ファイル名やアドレスを決めるものはありません：サービスが名前からアドレスを作り、
小文字、数字、ダッシュだけを残し、それ以外は拒否します。

ブラウザーはパッケージ(その `manifest.json` だけ)から欄を読み取ります。ファイル自体は、
公開を押したときにだけ外に出ます。

| | プリセット | テーマ |
|---|---|---|
| パッケージ | 最大 4 MB | 最大 8 MB |
| 頻度 | 同じアドレスから 1 時間に 5 件まで(プリセットとテーマの合計) | |

## 画像は自分では送れません {#the-picture-is-not-yours-to-send}

どちらのギャラリーにも、スクリーンショットを添付することはできません。画像は、サービスがパッケージから描画します。

**プリセット**の場合、サービスはパッケージからポップアップを、アプリが使うのと同じサンドボックス化されたドキュメントで、
ネットワークも独自のスクリプトもないブラウザーを使って一度、アプリが表示するサイズで描画します。
プリセットが対応しなければならないすべての状態で描画します：通常の解除、ブロンズ、シルバー、ゴールドのレア、
100% のポップアップ、進捗のステップです。カードには一度に 1 つが表示され、両側の矢印ボタンで
順に切り替えられ、拡大画像は表示中のものです。デザインするときは 6 つすべてを確認してください。1 つでしか
きれいに見えないプリセットは、ここでそれが分かります。

**テーマ**は色と数値なので、サーバーは AW Next のインターフェースの固定のサンプル(タイトルバー、プロフィールの行、ライブラリ、
最近解除した一覧、設定の画面)をあなたのテーマで描画して、それを撮影します。インポート前に設定が表示するサンプルと同じもので、
同じサイズです。毎回同じ 4 つの背景グラデーションの上に置かれるため、透過のテーマが色あせたデザインに
描画されることはなく、同じファイルの 2 回の描画は一致します。

サンプルのテキストはアプリのソースにある定数なので、カードにあなたのライブラリ、アカウント、パス、ゲームを載せたり、
送っていないバージョンの投稿を表示したりすることはできません。

## ファイルに含まれるもの {#what-travels-in-a-file}

**`.awpreset`** には、プリセットのドキュメントとスタイルシート、画像、フォント、サウンド、そしてその背後にある
デザイナーの設定が入っています。お使いのマシンに関するものは何もありません。

**`.awtheme`** には、色、グラデーション、フィット、エフェクトの設定、選んだ背景画像が入っていて、
それ以外は何もありません：スタイルシートも、マークアップも、スクリプトもありません。画像は、そのレイヤーから作られた名前のバイト列として
運ばれ、ピクチャフォルダーからのパスにはなりません。完全なリストは
[`.awtheme` 形式](../awtheme-format.md)にあります。

**ユーザーのスタイルシートのテーマはエクスポートできません。** `%APPDATA%\Achievement Watcher Next\themes` に置いた `.css` は
`.awtheme` ではなく、エクスポートは拒否します。`.css` 自体を共有してください。

## 背景やその他のアセット {#backgrounds-and-other-assets}

パッケージの中のものはすべて、ダウンロードする全員に再配布されるため、あなたが再配布できるものでなければなりません。

- 自分で作ったアートワーク、または再配布を許可するライセンスのもの。見つけた壁紙は、たいていどちらでもなく、
  購入したフォントもそうです。
- ロゴ、透かし、画像に焼き込まれたテキストがあるものは不可。テーマは見た目であり、広告枠ではありません。
- 職場でデスクトップの背景として通用しないものは不可。

色だけで作られたテーマは歓迎で、もっとも受け入れやすい種類です。

## クレジットとライセンス {#credit-and-licence}

カードに載る名前は、**クレジット** 欄に最終的に書かれているものです。エクスポート時にアプリが記録した
作者で始まるので、たいてい正しくなっています。別の名前を使っている場合は変更し、
空にすればカードに名前は載りません。メンテナーは、承認時にあなたのプロフィールへのリンクを追加することがあります。

**どちらのギャラリーに掲載されるものもすべて、
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) で公開されます。** 送信することで、それに同意し、
自分の作品であること、中のすべてを譲渡する権利が自分にあることを確認したことになります。

## 確認されること {#what-is-checked}

送信は 2 つの層を通過する必要があります。

**アプリ自身のリーダー。** インポート時に動作するモジュール `app/util/presetPackage.js` と `app/util/themePackage.js` が、
パッケージを検証します：マニフェスト、形式のバージョン、最小のアプリのバージョン、中のすべての
パス、ファイルの種類、サイズ、エントリポイントです。ギャラリーのサービスはこれらのファイルを
そのまま使うため、そこに追加されたルールは次のビルドでここにも適用され、アプリが拒否するものが
掲載されることはありません。

**ギャラリー自身の制限**。個人のインポートには不要なものです。

| | |
|---|---|
| ファイル名 | 小文字、数字、ダッシュで 2 ～ 48 文字。サービスが名前から作成します |
| パッケージ | プリセットは 4 MB、テーマは 8 MB |
| 画像 | サービスが状態ごとに一度描画し、1 つでも一覧が配信するサイズの範囲を超えると拒否されます(それぞれ最大 500 KB) |
| 名前 | ギャラリー内で一意。同じ名前の 2 つのエントリは、インポート時に衝突するためです |

パッケージの中のものは、検証中に実行されることはなく、ウェブサイトがパッケージを描画することもありません。カードには、サービスが作った
画像が表示されます。プリセットはアプリの中だけで、内蔵プリセットが使うのと同じサンドボックス化された通知ウィンドウで動作し、
テーマはどこでも何も実行できません。

## 拒否されるもの {#what-gets-refused}

- 他人の作品。本人が了承し、あなたがクレジットを付けた場合を除きます。
- 再配布できないアセット。
- 別のものを装うポップアップ：システムダイアログ、広告、訪問を促すアドレスなど。
- 背景画像に焼き込まれた広告、ロゴ、行動喚起。
- テキストが読めなくなるパレット。
- すでに掲載されているものとほぼ同じもの。

拒否した場合はチェックサムを保持してバイト列を削除するため、同じファイルをもう一度送っても、
2 回キューに入るのではなく認識されます。

## 自分の作品を更新または削除する {#updating-or-removing-yours}

パッケージ内のバージョンを上げた新しいファイルを同じ方法で送り、説明に以前のカードを置き換えるものだと書いて、
メンテナーがそちらを取り下げられるようにしてください。エントリを削除してもらうには、
[issue を作成](https://github.com/Shirowwww/Achievement-Watcher-Next/issues/new/choose)して、
どのカードかを伝えてください。

## パネルが表示されないとき {#when-the-panel-is-not-there}

ギャラリーのサーバーが応答しておらず、ページには隣に公開されたコピーが一覧されています。ギャラリーにすでにあるものは
すべてダウンロードできます。新しいものを送ることだけが待たされるので、あとでもう一度試してください。

パネルを表示させるサービスはプロジェクトが運営しており、このリポジトリには含まれていないため、
そのためにインストールするものは何もありません。

## Steam Achievement Notifier のテーマ {#themes-from-steam-achievement-notifier}

ここには掲載されておらず、今後も掲載されません。

SAN のテーマは、人々が直接やり取りする `.san` ファイルです。SAN のリポジトリにはテーマのフォルダー、Wiki のリスト、
フィードがないため、ビルドが参照できる先がありません。ファイルは作った人のもので、
再配布のライセンスは与えられておらず、SAN のリポジトリにはそもそもライセンスがありません。
どちらをここにコピーしても、他人の作品を許可なく再公開することになります。

代わりに、AW Next があなたのものを読み取ります。**設定 → 通知プリセット → SAN テーマを読み込む** は `.san`
ファイル、またはすでに展開されたテーマの `usertheme.json` を読み取り、**この PC の SAN から読み込む** は
SAN 自身の設定を読み取ります。どちらの場合も、テーマは AW Next のプリセットになり、SAN 自身のエンジンで
SAN のサイズで描画され、ほかのものと同じように `.awpreset` としてエクスポートされます。取り込まれるものは
[プリセット](presets.md#import-a-theme-from-steam-achievement-notifier)にあります。

自分のものをインポートしたなら、それをエクスポートして送信してください。そうすればあなたのプリセットとなり、あなたのクレジットが付きます。

- [Steam Achievement Notifier](https://github.com/SteamAchievementNotifier/SteamAchievementNotifier)
