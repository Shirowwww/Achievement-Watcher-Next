# プリセットとプリセットデザイナー

**プリセット**とは、ゲーム内オーバーレイのポップアップの見た目のことで、レイアウト、色、動き、そして
レアな解除や 100% 達成の描き方を含みます。**設定 → 通知 → プリセット** で選び、
**設定 → 通知プリセット** で自作し、または誰かが共有したものをインポートします。
プリセット設定の隣にあるグリッドボタンは、すべてのプリセットをカードの画像として表示します。クリックすると
そのプリセットを使います。

> [!NOTE]
> プリセットが装飾するのはゲーム内オーバーレイです。**通知の種類** を *Windows 通知* にすると、
> プリセットが記述するものは何も描画されず、通知プリセットのタブも表示されません。

## 内蔵プリセット {#the-bundled-presets}

AW Next には 10 種類が付属し、それぞれ構図、書体、動き、色が異なります。

| プリセット | 内容 |
| --- | --- |
| **AW Next** | 既定。アプリ自身のパレット、左端に沿ったアクセントのレール、輪のついたアイコン、実績の上にゲーム名。 |
| **Steam Modern** | テキストの後ろに Steam のマークがある濃紺のプレート。角は直角で、下端からせり上がります。 |
| **Steam Original** | 現在の Steam クライアントが描くポップアップのコピー：スレート色のグラデーション、大きく薄い Steam のマーク、四角いアイコン、レアな解除にだけ付く金色の縁。 |
| **Epic Games** | フラットで中立的、肩が四角く、セットの中でもっとも余白が広く、左端に沿って罫線が 1 本。 |
| **PlayStation** | コンソールの書体と、灰色から黒への長いパネル。右側の輪の中で PlayStation のマークが脈打ちます。 |
| **Xbox** | 暗いピル型で、丸いアイコンの周りを緑の弧が一度だけ回り、安定したリングに落ち着きます。 |
| **Cover** | ゲームのアートワークを背景にしてゆっくり流れ、テキストの下にスクリムがあり、セットの中で最大の文字。 |
| **Glass** | 半透明で控えめ：アクセントバーがなく、レアまたは 100% の解除が色をもたらすまで無彩色。 |
| **Arcade** | 黒地に蛍光グリーン、等幅で大文字、走査線と硬いオフセットの縁。レアな解除では琥珀色に切り替わります。 |
| **Slim** | 真っ黒な背景の低いもの：ほかと同じ幅で高さは半分。OLED パネルで消えるように作られています。 |

すべてのプリセットは同じ幅なので、プリセットを切り替えてもポップアップが横にずれることはありません。

### すべてのプリセットが描く 4 つの状態 {#the-four-states-every-preset-draws}

| 状態 | 見た目 |
| --- | --- |
| **通常** | プリセット自身のアクセント。 |
| **レア** | 5% 以下はゴールド、10% までシルバー、15% までブロンズ(上限は **設定 → 一般 → レア度のしきい値** で変更できます)。カードに解除率が表示され、グローが強まり、縁が追加されます。 |
| **100%達成** | 冷たく明るい処理と、二重になった縁。 |
| **進捗** | `current/max - %` のラベルが付いた進捗バー。 |

選んだプリセットがレアと 100% を自分で描くため、プリセットの設定は 3 つではなく 1 つです。エミュレーターごとの
上書きは **設定 → 通知 → エミュレーター**(詳細モード)にあり、Xenia、
RPCS3、shadPS4、Kyty がそれぞれ専用のプリセットとサウンドを持てます。

プリセットは、自分で設定しない限り通知タブで選んだサウンドを使うので、見た目を変えても
聞こえる音は変わりません。共有されたプリセットは独自のサウンドを持てます：
[プリセットを共有する](#share-a-preset)を参照してください。通知タブの **不透明度**(30% から 100%)で、
ポップアップの透け具合を決めます。

> [!NOTE]
> 以前の名前で付属していたプリセットも引き続き解決されます：`Shirow`/`Default`/`Midnight`/`xqjan` は
> **AW Next** に、`Steam` は **Steam Modern** に、`PS4`/`PS5 enhanced` は **PlayStation** に、
> `Xbox 360`/`Xbox One` は **Xbox** に、`Game Cover`/`Sunset` は **Cover** に、`Clean`/`Modern`/`Smooth Pop` は **Glass** に、
> `Neon Future`/`LAZ0RBOX` は **Arcade** に、コミュニティの `ArmsofGod`、`Epic Preset`、
> `mudoss` は **Pantheon**、**Onyx**、**Outline** になります。コミュニティの **Hexagon** と **Indiana** は
> 削除され、これらと `TigerDX Award` は **AW Next** に置き換わります。これらの名前のいずれかを持つ自作のプリセットは、
> 置き換え先より優先して使われます。

### 出発点 {#starting-points}

最初の行には 14 種類の完成したデザインがあります：*Classic*、*Aurora*、*Neon*、*Cover*、*Minimal*、
*Console*、*Terminal*、*Slate*、*Paper*(唯一の明るいデザイン)、*Ember*、*Frost*、*Poster*、*Pixel*、
*Ribbon*。それぞれは通常のコントロールの値の組み合わせにすぎないので、1 つ選ぶことは、すべての
コントロールを手で動かすのと同じです。そのまま使っても、土台にしても構いません。

| 操作 | 内容 |
| --- | --- |
| **おまかせ** | まだ試していないデザインを作ります：カードの種類(フラット、グラデーション、ネオン、アートワークの上、ガラス風、ターミナル、明るい)を選び、その種類で許される範囲ですべてのコントロールをランダムに決めます。 |
| **複製** | 現在のデザインを保ち、名前を空けるので、次の **プリセットを作成** で、元のプリセットを置き換えずに新しいプリセットが追加されます。 |

**プリセットを作成** を押すまで、何も保存されません。

### プレビュー {#the-preview}

プレビューは通知そのもので、ゲーム内と同じページ、スタイル、エンジンで描画されます。コントロールを
スクロールしても、パネルの上部に固定されたままです。

| コントロール | 表示内容 |
| --- | --- |
| **カード** | ポップアップを本来のサイズで表示します。ピクセルサイズとプレビューのズームがその下に表示されます。 |
| **見比べる** | 4 つの通知を 2 × 2 で同時に表示します。 |
| **画面** | 模擬ディスプレイ(**720p**、**1080p**、**1440p**、**4K**)上のポップアップを、実際の相対的な大きさで、通知が表示されるように設定された隅に表示します。 |
| **通常 / レア / 100% / 進捗** | プリセットが正しく見える必要がある 4 つの通知。**見比べる** では、選んだものが通常の強さで描かれます。 |
| **再生** | 登場、保持、退場を、プリセット自身のタイミングで一度再生します。 |
| **背景** | ポップアップを評価する背景：透明、暗いシーン、明るいシーン、またはライブラリのアートワーク。 |
| **位置 / サイズ** | 通知タブの同名の設定を反映し、変更もできます。**画面** 表示でのみ表示されます。手動で配置したポップアップは下部中央に描かれ、ラベルが付きます。 |

### 全体の見渡し方 {#finding-your-way-around}

デザイナーには 9 つのグループと 60 ほどのコントロールがあり、フィルターと取り消し履歴があります。

| | 内容 |
| --- | --- |
| **フィルター** | グループの上のボックスに入力すると、一致するコントロールだけが残ります。ラベル、ドロップダウンの語、プロパティ自身の名前を検索するので、`corner` でも `radius` でも同じスライダーが見つかり、`.awpreset` から読み取った名前でもそのコントロールが見つかります。**詳細** の中に一致があると、それが開きます。**Esc** でボックスを消去します。 |
| **元に戻す / やり直し** | フィルターの隣の 2 つの矢印、または **Ctrl+Z** と **Ctrl+Y**(**Ctrl+Shift+Z** も使えます)。スライダーを 1 回ドラッグすると 1 ステップです。プリセットの読み込み、出発点の選択、リセットを押すと、新しい履歴が始まります。 |

**レイアウトとサイズ** と **色と背景** は最初から開いています。ほかのグループはクリックで開き、ほとんどに
細かい調整用の **詳細** の開閉部分があります。

### コントロール {#the-controls}

インターフェースが **シンプル** モードのときは、詳細の部分は表示されません。

| グループ | 対象 |
| --- | --- |
| **レイアウトとサイズ** | アイコンを左、右、テキストの上に置くか、置かないか。テキストの揃え。ポップアップの幅、余白、間隔。そして実績の上に**ゲーム名**を表示するかどうか。 |
| **テキスト** | フォント(5 つのファミリーのいずれか、または**自分のフォントファイル**：TTF、OTF、WOFF、WOFF2 で 4 MB まで、プリセットにコピーされます)、タイトルと説明のサイズ、説明を折り返せる行数、タイトルの色。詳細では：タイトルの太さ、大文字、字間、テキストの影、すべての文字の縁取り。 |
| **色と背景** | 単色、角度つきの 2 色グラデーション、**ゲーム自身のアートワーク**、または**自分の画像**(プリセットにコピーされます)を、暗くし、ぼかし、枠をつけてテキストの背後に。さらにテキストの色、アクセント、不透明度。詳細では、背景の上でテキストの下に重なる**テクスチャ**(グリッド、ドット、ハッチング、斑点)。 |
| **アイコン** | サイズ、**形**(角丸の四角、円、スクイークル、六角形、ひし形)、詳細ではアクセントカラーの枠線とグロー。角の丸みは角丸の四角にだけ適用されます。**ロゴ**(PNG、JPEG、GIF、WebP、BMP で 5 MB まで)は、隅または辺の中央のテキストの背後に、サイズと端からの距離を指定して置けます。フォントと同様にプリセットにコピーされます。 |
| **枠と角** | 角の半径、アクセントバー(または全体の輪郭線、またはなし)をどの辺に付けるかとその太さ。詳細では、自分の色の枠線。 |
| **影とグロー** | ドロップシャドウの深さ、アクセントのグロー、ポップアップの表示中にそのグローが**脈打つ**か**呼吸する**か。 |
| **アニメーションと表示時間** | ポップアップが入ってくる辺と出ていく辺(またはフェード、ズーム)、そして表示時間。詳細では：移動距離、登場と退場の速さ、登場のカーブ(スムーズ、リニア、バック、ゆるやか、スナップ、弾性)と**退場のカーブ**。 |
| **レアと100%達成** | レアな解除と 100% の色とグロー、カード全体を染める**状態の色合い**、進捗バーを表示するかどうか、**レア度バッジ**が解除率を表示するかどうか。詳細では：進捗バーの太さ、シルバーとブロンズのティア、隠し実績のタイトルの前の**南京錠**。 |
| **サウンド** | 通知タブのサウンドの代わりに、このプリセットが再生するサウンド。なしにするには **アプリの設定** のままにします。 |

| 操作 | 内容 |
| --- | --- |
| **画面に表示** | デザインを本物のオーバーレイのポップアップとして、フルサイズで、設定された位置に、プレビューが示す状態で、保存せずに描画します。 |
| **プリセットを作成** | 保存して、有効なプリセットとして選択します。 |
| **プリセットを更新** | 名前がデザイナーで作ったプリセットと一致すると同じボタンがこうなります：別のものを追加せず、そのプリセットを置き換えます。 |
| **プリセットを編集** | 自分で生成したプリセットを、保存されたままのすべての値でコントロールに読み込み直します。 |
| **リセット** | コントロールを既定のデザインに戻します。ディスク上のものは何も変わりません。 |
| **名前を変更** | 生成したプリセットを読み込むと表示されます。名前欄に新しい名前を入力して押すと、プリセットがディスク上で名前変更され、それを指していた通知設定も追随します。 |
| **削除** | 生成したプリセットを読み込むと表示され、確認のあとで削除します。 |
| **エクスポート** / **インポート** | プリセットをマシン間で移動します：[プリセットを共有する](#share-a-preset)を参照してください。 |

このデザイナーが生成したプリセットだけが再度開いたり削除したりでき、デザイナーは設定を生成したファイルの隣の
`aw-preset.json` に保存します。そのファイルがあるからプリセットを編集できるのです。内蔵プリセットと
手書きのプリセットには一切触れません。

> [!NOTE]
> すでに作ったプリセットは、生成されたままのファイルを保ちます。デザイナーで開いて保存すると、
> 現在の既定値が適用されます。その中には、レアな解除と 100% 達成でポップアップ全体を塗り替えることが
> 含まれます。

> [!NOTE]
> 作成したプリセットは、インストールフォルダーではなく `%APPDATA%\Achievement Watcher Next\presets\Users Presets` に保存され、
> アプリのアップデート後も残ります。

### レイアウトエディター {#the-layout-editor}

プレビューの下の **エディター** は、デザインを全画面で開きます。中央にカード、左にそのレイヤー、
右に選択したものの設定が並びます。カード上のものをドラッグすれば移動し、角を引けばリサイズでき、丸いハンドルで
回転します。初めて開くと、短いツアーで各部の場所を案内します。**?** はすべてのショートカットを一覧し、
ツアーをもう一度再生できます。

| | 内容 |
| --- | --- |
| **追加** | テキスト、画像、長方形、楕円、線、または**アイコン**(トロフィー、メダル、王冠、星、ほかに 8 種)。それぞれが独立したレイヤーです。 |
| **アニメーション画像** | GIF またはアニメーション WebP(5 MB まで)がカード上で再生されます。**ポップアップのたびに GIF を再生** は、ポップアップが表示されるたびに最初のフレームから開始します。 |
| **ポップアップの語句** | テキストには `{game}`、`{title}`、`{detail}`、`{rarity}`、`{tier}` を含められます。テキスト欄の下のボタンで挿入でき、ポップアップがゲーム名、実績、その説明、解除率、ティア名をそこに入れます。 |
| **塗り** | 図形やアイコンは、色、グラデーション、円形グラデーション、ポップアップのティアの色(カードとともにブロンズ、シルバー、ゴールドに変わります)、またはポップアップにかかわらず 1 つのティアの色で塗られます。 |
| **図形** | 星には頂点の数と深さ、矢印には頭と軸、三角形には底辺に沿って動く頂点があります。楕円以外のすべての図形は角を丸くでき、輪郭線や線は破線や点線にでき、図形、アイコン、画像は反転できます。画像はこれらのどの形にも切り抜けます。 |
| **透過** | 線以外の図形は透過に切り替えられます。それ自体は何も描きません。その下に重なっているもの、つまりカード、そのアイコンとテキスト、下の要素は、その形の範囲で切り取られ、穴からデスクトップが見えます。その上の要素は残ります。透過の図形は静止し、内蔵プリセットの上ではこのスイッチは表示されません。 |
| **影とグロー** | テキスト、図形、アイコンは、黒、ポップアップのティアの色、または自分の色で、影を落としたり光ったりします。 |
| **一度に 1 つの状態** | エディターは、プレビューが示す状態(通常、ブロンズ、シルバー、ゴールド、100%、進捗)に対して作業します。**編集：すべて** は要素をすべての状態で変更し、**編集：ゴールドのみ**(または表示中の状態)はその状態だけで、色から位置まで何でも変更し、その時点で追加した要素はその状態にだけ表示されます。**表示** は要素を同じ方法で隠したり表示したりするため、ゴールドの解除にだけ出る王冠は、ゴールド以外のすべてでオフにした 1 つのアイコンです。選択した要素に専用の設定がある状態にはその旨が表示され、**基本に戻す** で再びほかに追随します。カードの各部分(タイトル、アイコン、説明)も同じように働きます。 |
| **登場とループ** | カードが表示されたあとに要素がどう入ってくるか(フェード、上昇、落下、横から、ズーム、ポップ、揺れ、フラッシュ。テキストは自分で打ち出すこともでき、レア度や進捗のテキストはカウントアップします)とその遅れ。続いて、ポップアップの表示中に動き続けるかどうか：脈動、浮遊、スイング、回転、輝き。作業中、エディターは静止しています。**再生** で動きを確認できます。 |
| **タイムライン** | エディター下部のバーに、各要素がいつ、どのくらいの間入ってくるかが表示されます。バーをドラッグして登場を移動または伸縮し、**再生** を押してカードを見たり、ルーラーに沿ってドラッグして 1 つの瞬間で止めたりできます。アニメーションの設定が変わるまでは折りたたまれたままです。 |
| **テキストボックス** | タイトル、説明、ゲームの行は、言い換えたり、塗り、余白、角丸、輪郭線を持つ専用のボックスを与えたりできます。進捗バーには太さとトラックの色があり、アイコンは四角にできます。 |
| **位置とサイズ** | X、Y、幅、高さの数値入力と、要素をカードの端や中央に揃える 6 つのボタン。 |
| **レイヤー** | 目のアイコンで要素を隠します。南京錠は要素を所定の位置に固定します。ロックを外すまで移動、リサイズ、削除ができず、クリックはそれを通り抜けます。矢印で重ね順を変えます。 |
| **複数を一度に** | **Shift** または **Ctrl** + クリックで要素を選択に加えたり外したりでき、何もない場所からのドラッグで枠が触れたものすべてを選び、**Ctrl+A** ですべてを選びます。グループは一体として移動し、カードやそのグループ自身に揃え、複製、コピー、削除が一度にできます。 |
| **コピーと貼り付け** | **Ctrl+C** と **Ctrl+V** で選択をコピーします。ほかのプリセットへもコピーできます。カラーピッカーには、デザインがすでに使っている色が表示されます。 |

このバージョンより前に作られたプリセットのファイルは引き続き動作し、これらを何も使わないプリセットは、これまでどおりの
見た目とエクスポートになります。

## 内蔵プリセットをカスタマイズする {#customize-a-bundled-preset}

デザイナー上部の **プリセットをカスタマイズ** は、アプリに付属するプリセットから始めます。そのプリセットは
コピーも編集もされません。保存するレイヤーは、それを指名する数行と、変更した値であり、
出荷されたままの内蔵プリセットの上に重ねられます。のちのバージョンで内蔵プリセットが改良されれば、
あなたのレイヤーも一緒に改良されます。

変更するセクションにチェックを入れます：**背景**(色またはグラデーション)、**テキストの色**、**アクセント**、
**枠線**、**グロー**、**フォント**(5 つのファミリーのいずれか、または自分のフォントファイル)、**ロゴ**。
コントロールは内蔵プリセット自身の色から始まります。プレビューと **画面に表示** は、
あなたのレイヤーを重ねた内蔵プリセットを表示します。

- 同じカードを描く **既定のプリセット** の一覧にあるプリセットに対して働きます。コミュニティの
  プリセット(Batman、Onyx、Outline など)は独自のレイアウトを描くため、対象外です。
- レイヤーは、それを作ったインストールの内蔵プリセットの上にだけ存在するため、`.awpreset` としてエクスポート
  できません。デザインを共有するには、デザイナーで作ってください。
- **OBSブラウザソース** はレイヤーを無視し、既定のプリセットを表示します。
- ポップアップは内蔵プリセットのウィンドウサイズを保つため、大きなグローや枠線は切り取られることがあります。

## Steam Achievement Notifier のテーマをインポートする {#import-a-theme-from-steam-achievement-notifier}

**Steam Achievement Notifier**(SAN)のテーマは、そのまま取り込めます。AW Next はインポートしたテーマを
SAN 自身のカードレイアウトで描画するため、SAN にあったときと同じ見た目と動きになります：11 種類のレイアウトすべてが、
SAN の文字サイズとテーマ自身のサイズ設定で再現されます。**通知プリセット** タブの 2 つのボタンで
テーマをインポートします。

- **SAN テーマを読み込む** は、1 つの `.san` ファイル、または SAN がすでに展開したテーマの中の
  `usertheme.json` を、隣にある画像とサウンドとともに読み取ります。
- **この PC の SAN から読み込む** は、ここに SAN がインストールされていれば SAN 自身の設定を読み取り、
  このPCに保存されているすべてのテーマを一度にインポートします。使用中の 4 つのテーマ(通常、準レア、レア、100%)は
  1 つのプリセット `SAN - <theme name>` になり、SAN と同じように切り替わります。保存されているほかのテーマは
  それぞれ単独のプリセットになります。もう一度実行すると、コピーを追加せずにそれらのプリセットを更新し、
  同じ名前の自作のプリセットには決して触れません。

インストール済みの SAN プリセットは自動的に再構築されます。

### 取り込まれるもの {#what-comes-across}

テーマが保持するものすべて：全設定、その画像(背景、マスク、ロゴと装飾、
アイコンの枠、パーセンテージのバッジ、隠し実績のアイコン)、フォント、サウンド(状態ごとに 1 つ、または
SAN がランダムに選ぶフォルダー)。プリセットがそのすべてを持ち運ぶため、あとから SAN は不要で、
`.awpreset` としてエクスポートできます。

見た目はデザイナーのスライダーではなく SAN のものです。**プリセットを編集** はそれを画像として表示し、その下に
2 つの選択のためのパネルがあります。

- **トロフィー画像**：ブロンズ、シルバー、ゴールドのトロフィーを描くテーマ用。*ティアに従う* は
  解除に合う 1 つを表示し、1 つの色を選べば常にそれを表示します。
- **ティアごとのテーマ** は、1 つのティアを、サウンドも含めて別のインポート済み SAN テーマで描画するため、
  ゴールドの解除をブロンズとまったく違う見た目にできます。

そのほかはすべて SAN で変更してから、もう一度インポートします。

通知が受け取る状態は、AW Next のレア度の設定に従います。100% 達成は SAN の 100% のカードを使います。レアモードでは
ゴールドとシルバーがレアのカードを、ブロンズが準レアのカードを使い、トロフィーモードでは
ゴールド、シルバー、ブロンズがそれぞれレア、準レア、通常を使います。AW
Next で選んだレアまたは 100% のサウンドはテーマ自身のものより優先され、ポップアップの位置とサイズは **通知** タブで決まります。

インポート後のレポートには、取り込めなかったものが一覧されます：テーマが名指ししているのに含まれていなかったファイル、
拒否された画像やフォント、このバージョンがまだ描画できない新しい SAN の設定です。これは
アプリのログにも書き込まれます。

### インストール前に確認されること {#what-is-checked-before-anything-is-installed}

テーマファイルは他人のマシンから来るため、`.awpreset` と同じルールが適用されます。中のものは何も
実行も評価もされず、その `usertheme.json` だけが読み取られます。すべてのパスは、それが入っていた
パッケージに対して検証され、SAN が書き込む絶対パスはファイル名としてだけ読み取られます。画像、
フォント、オーディオだけが、ファイルの種類とサイズの上限のもとで取り出されます。スクリプトを実行できる SVG や、
フォントではないファイルは拒否されます。すべての設定は型と範囲が検証されます。失敗したインポートは、
すでにあるプリセットに一切手を付けません。

## プリセットを共有する {#share-a-preset}

**通知プリセット** タブの **エクスポート** と **インポート** は、プリセットを 1 つの
`.awpreset` ファイルとしてマシン間で移動します：スタイル、使用するすべての画像とフォント、デザイナーの設定、メタデータです。

[プリセットギャラリー](../gallery/)にはこれらのファイルが集められています。閲覧して、ダウンロードしてインポートするか、
自分のものを追加できます。投稿が満たすべき条件と、一覧に載る前に確認される内容は、
[コミュニティギャラリー](community-galleries.md)にあります。

**エクスポート** は、カードが表示しているものを **名前** 欄の名前で書き出します：コントロールにあるデザインが
保存済みかどうかにかかわらず対象なので、作成する前の作業中のプリセットも共有できます。**プリセットを編集** で選択した
インポート済みのプリセットは、その見た目がコントロールでは表現できないファイルに入っているため、ディスクからそのまま
エクスポートされます。移動するのはプリセットだけで、マシンのパスも、アカウント名も、
自分の設定も含まれません。

**インポート** はファイルを尋ね、検証して、`presets\Users Presets` にインストールします。名前が
自分のプリセットや内蔵のプリセットとすでに重複している場合は、**両方を保持**(インポートされるものは
`Name (2)` になります)か **置き換える** を選びます。答えるまで何も書き込まれません。

インポートしたプリセットは **プリセットを編集** に表示されて選択され、そこから再びエクスポートや削除ができます。
デザイナーで作ったプリセットは、さらに編集できるよう完全な状態で戻ります。手書きのプリセットは
コントロールでは再現できないファイルから見た目を得ているため、コントロールはそのままで、名前欄は
空のままです。

### インストール前に確認されること {#what-is-checked-before-anything-is-installed-1}

パッケージは全体が検証され、次の場合は一部だけがインストールされることなく、全体が拒否されます。

- プリセットのパッケージではない、またはマニフェストがない、もしくは形式が不正である。
- 実行中のものより新しい AW Next、または新しいパッケージ形式を必要とする。
- 形式が記述していないファイルを含む：プログラム、スクリプト、または
  `preset/` と `sounds/` の外にあるもの。
- 中のパスが、自身のフォルダーの外を指している。

パッケージの中のものは、検証中もインストール中も、実行も評価もされません。プリセットのページは、
あとで内蔵プリセットと同じサンドボックス化された通知ウィンドウで描画されます。

### パッケージの内容 {#what-a-package-contains}

```text
manifest.json     name, description, author, version, tags, format version,
                  minimum AW Next version, and the designer settings
preset/           index.html, style.css, images and fonts (relative paths only)
sounds/           optional audio, added to your sound list on import
```

マニフェストは、インストールされたプリセットの隣に `aw-package.json` として保持されます。これにより、アプリは
そのプリセットがインポートされたもので、再び削除できることを知り、説明とクレジットが次のエクスポートに引き継がれます。

自分でインポートしたサウンドはプリセットとともに移動します。内蔵のサウンドは、マニフェストが名前を
指定しており、どのインストールにもあるため、移動しません。インポートは選択中のサウンドを変更せず、
すでにあるサウンドを上書きすることもありません。同じ名前の別のファイルは `name (2)` として届きます。

任意の `author` フィールドは、プリセット自身のファイルからのみ入力されるため、あなたがそこに書かない限り、
誰かのクレジットになることはありません。
