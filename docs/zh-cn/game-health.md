# 游戏状态

当游戏出现异常时，请先打开它的 **游戏状态** 面板。它会说明 AW Next 能否看到该
游戏、读取它的成就并提示它的解锁，并且只提供适用的修复。

可通过游戏磁贴右上角的 **工具** 按钮，或游戏的
右键菜单打开它。面板有三个标签页：**状态**、设置游戏时要监视的程序的 **可执行文件**，
以及 **通知**，游戏可以在其中使用自己的弹窗预设、位置、
声音和大小（见[按游戏设置](notifications.md#per-game-behavior)）。

## 三种状态 {#the-three-states}

| 状态 | 含义 |
|---|---|
| **就绪** | 游戏已被检测到，其成就数据可用，AW Next 正在监视它的解锁。 |
| **需要检查** | 游戏可以运行，但设置的一部分不完整。检查项会显示是哪一部分。 |
| **未跟踪** | 缺少某些必要条件，因此无法记录任何解锁：找不到游戏、它没有成就数据，或缺少写入其解锁记录的模拟器。 |

状态下方的句子给出原因，检查项显示是哪一部分出了问题，修复
按钮则恰好针对它。

- **简易** 模式用通俗的话说明结果（*已找到成就数据*、*游戏启动时检测*）。
  **高级** 会增加确切的数量、被监视的进程和通知渠道。
- **技术细节** 位于两种模式的底部，包含每一个原始值。报告错误时请按 **复制**。
  较长的值在悬停时滚动。

主机模拟器游戏不会被要求提供 Windows 可执行文件或游戏文件。

有些游戏无论如何设置都不会在离线时记录任何内容。Halo: Campaign Evolved 和 The Crew
Motorfest 的成就由发行商的服务器授予，所以破解版不会保存任何成就。它们的
面板从首次启动起就会这样说明。

## 检查项 {#the-checks}

| 检查项 | 回答的问题 | 典型修复 |
|---|---|---|
| **游戏文件** | 安装文件夹还在吗？ | **定位游戏** |
| **可执行文件** | 游戏时应监视哪个程序？ | **定位游戏** |
| **游戏标识** | 这款游戏被匹配到哪个 AppID 和平台？简易模式不显示。 | **修正游戏 ID 文件** 或 **手动设置 AppID** |
| **成就数据** | 有成就列表吗？它完整吗？ | **重写成就数据** |
| **模拟器配置** | 需要 Steam 模拟器的游戏有没有模拟器，由哪一个提供支持？对于 Ubisoft 游戏，这还涵盖 Uplay 加载器，以及它是否曾请求过成就。 | **安装模拟器文件**、**切换到受支持的模拟器** 或 **修复 Ubisoft 成就支持** |
| **进度** | 是否已找到任何解锁或存档？ | 启动游戏并解锁一些东西 |
| **进度计数器** | 对于跟踪统计数据而不是简单解锁的 CODEX/RUNE 类游戏，AW Next 是否已获取每个成就背后的统计数据？仅对使用统计数据的游戏显示。 | **获取进度计数器** |
| **游戏启动检测** | 后台跟踪器能注意到这款游戏何时启动吗？它本身不记录任何解锁：那是模拟器的工作。 | **监视这款游戏** |
| **通知** | 这款游戏最近一条通知是通过哪个渠道送达的，原因是什么？ | **发送测试通知** |

## 修复 {#the-repairs}

面板只显示能修复这款游戏的修复项。每一项都会说明它会更改什么，以及
之前的文件保存在哪里。没有备份或确认，就不会重写任何内容。

| 修复 | 作用 |
|---|---|
| **定位游戏** | 打开选择器，选择要监视的可执行文件。 |
| **打开游戏文件夹** | 在资源管理器中打开安装文件夹。 |
| **重写成就数据** | 写入成就列表、图标和模拟器设置，会先把现有文件复制到备份。 |
| **安装模拟器文件** | 把受支持的模拟器版本下载到游戏文件夹，被替换的文件保留为 `.bak`。 |
| **切换到受支持的模拟器** | 适用于由另一个什么也没记录的破解提供支持的游戏：在其上安装受支持的模拟器，并把那个破解的配置重命名为 `.bak`。 |
| **撤销模拟器切换** | 在上面两项之一运行过的地方出现。从 `.bak` 副本恢复游戏自己的文件，并移除受支持的模拟器。 |
| **修正游戏 ID 文件** | 当模拟器宣告的是一款游戏，而 AW Next 匹配到另一款时，重写 `steam_appid.txt`。它会询问正确的 AppID，并建议 AW Next 的匹配结果，同时保留之前的文件。 |
| **获取进度计数器** | 针对 CODEX/RUNE 类游戏，向 Steam 询问是哪个统计数据驱动每个成就。不会向游戏文件夹写入任何内容。 |
| **修复 Ubisoft 成就支持** | 对于兼容的 Ubisoft 游戏，在一次事务中重写加载器配置、架构和存档重定向，并备份每个被改动的文件。见 [Uplay 设置](uplay-r2.md)。 |
| **离线启用成就** | 适用于这样的 Ubisoft 游戏：加载器日志证明它因为认为自己已退出登录而从未请求过成就。在游戏旁边的 INI 中添加一个占位的会话密钥；再按一次即可移除。见 [Uplay 设置](uplay-r2.md#a-game-that-never-asks-for-an-achievement)。 |
| **监视这款游戏** | 把游戏添加到后台跟踪器，以便记录游戏时长和实时解锁。 |
| **恢复进度通知** | 为你静音过的游戏重新开启进度通知。 |
| **发送测试通知** | 使用这款游戏的名称和美术图，通过它实际会使用的渠道发出一条通知。 |

> [!IMPORTANT]
> 不匹配并不总是模拟器的错：如果它是专门按磁盘上的 ID 设置的，
> 请不要动它。**手动设置 AppID**（右键单击）可以一劳永逸地解决文件夹名称不匹配的问题，而不是
> 每次都去修正文件。见 [Goldberg / GBE 设置](emulator-setup.md#set-appid-manually)。

## 常见状态及对策 {#common-states-and-what-to-do}

| 面板显示 | 通常的含义 |
|---|---|
| *找不到成就列表* | 游戏没有成就，或其来源被关闭。请检查 **设置 → 来源**。 |
| *这款游戏需要 Steam 模拟器，但尚未设置* | 使用右键菜单中的 **应用模拟器修复…**。见 [Goldberg / GBE 设置](emulator-setup.md)。 |
| *读取它的模拟器文件缺失* | **安装模拟器文件** 会放入匹配的运行时。 |
| *成就列表与游戏将要查找的内容不匹配* | **重写成就数据**。这通常是 repack 更新的结果。 |
| *尚未找到成就进度* | 对于设置后还没玩过的游戏来说是正常的。启动它并解锁一些东西。 |
| *AW Next 在这款游戏运行时没有监视它* | **监视这款游戏** 会把它添加到跟踪器。 |
| *无法发送最近一条通知* | 发送测试通知，然后见[通知](notifications.md#if-a-test-or-unlock-does-not-appear)。 |
| *Windows 在游戏期间隐藏了最近一条通知* | 因为游戏处于全屏或开启了勿扰模式，它直接进入了通知中心。开启[高优先级通知](notifications.md#priority-windows-notifications)，或使用自动或游戏内叠加层。 |
| *正常 - Windows 备用已启用* | 不是故障。自动推送为这款游戏选择了 Windows 通知；见“[自动”如何判断](notifications.md#how-automatic-decides)。 |
| *游戏从未请求过成就* | 它把空的 Ubisoft 会话理解为已退出登录。**离线启用成就** 可解除阻碍；不会向任何地方发送内容。之后启动一次游戏。 |
| *离线成就已开启，请启动一次游戏* | 设置已写入，但还没有做出任何判断。旁边的按钮现在显示为 **关闭离线成就**。 |
| *由 ALI213、OnlineFix、GBE Fork… 提供支持* | 实际读取这款游戏的模拟器，其名称根据游戏自己的文件得出。以这种方式运行的 Ubisoft 游戏不会提供 Uplay 修复：它的 Uplay 层是未使用，而不是坏了。这涵盖保留 Valve 的 `steam_api64.dll` 的发布版：从 `Steam\steamclient64.dll` 运行的 RUNE 版本，或加载自己重命名的 GBE Fork（`steam_api64.v38`）的 VOICES38 发布版；绝不要在后者上安装模拟器。online-fix 的 Ubisoft 版本会被识别，并且对其进行成就修复时会警告联机游戏可能停止工作。 |
| *只缺少部分图标* | **重写成就数据** 会下载缺失的图标。 |
| *运行了一个多小时，却没有记录任何成就* | 为游戏提供支持的破解很可能从不报告成就。如有提供，请使用 **切换到受支持的模拟器**；否则请检查游戏是否从自己的文件夹启动。 |
| *游戏 ID 文件*，且有指向这款游戏的 Steam 快捷方式 | Steam 启动非 Steam 快捷方式时，旁边没有 `steam_appid.txt`，所以模拟器会保存到另一个 ID 下。**重写成就数据** 会在那里写入该文件。 |
