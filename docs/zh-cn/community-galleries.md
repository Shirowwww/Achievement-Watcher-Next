# 社区库

两个库，一个服务，一套规则。

| | | |
|---|---|---|
| [预设库](../gallery/) | `.awpreset` | 通知弹窗：布局、字体、颜色、动效和声音 |
| [主题库](../gallery/themes/) | `.awtheme` | 应用的其余部分：窗口、标题栏、游戏库、成就列表、设置和叠加层 |

要从任一库下载，请取得文件，然后使用 **设置 → 通知预设 → 导入** 或
**设置 → 外观 → 导入**。本页介绍另一面：如何添加作品、会检查什么，
以及卡片上可以写什么。

## 提交作品 {#sending-one}

两者的流程相同，在你按下 **发布** 之前，任何内容都不会离开你的浏览器。

1. **导出它。** 预设使用 设置 → 通知预设 → 导出，主题使用 设置 → 外观 →
   导出。文件中已带有名称、说明、版本、标签和所需的 AW Next
   版本。
2. 在库页面的 *提交你的作品* 面板中**选择文件**，或把它拖到面板上。选择
   不会发送任何内容：文件会等待你填写其余信息，面板会说明其中包含什么。
3. **检查卡片上应该写什么。** 选择文件后，四个框会立即从包中填入：
   **名称**、一行**说明**、**标签**和**署名**。署名是你导出时应用
   记录的作者，也就是你使用的名字，只有在你选择
   不署名时才为空。输入标签并按 Enter 可将其变成标签块；单击标签块可删除它。

   **名称是唯一必须填写的框。** 它是卡片的标题，也决定文件发布时的地址，
   而替别人取的名称，最后是由审核人员来改写的。
   在填写之前，发布按钮保持无效。另外三个可以留空，卡片在这些位置就不会带任何内容。
4. **按下发布。** 需要几秒钟，因为图片是渲染出来的，而不是猜的。然后
   是等待：在维护者批准之前，库中不会出现任何内容。

这些框中的所有内容都是**建议**。它只在填写之处覆盖包中的内容，会像清理清单一样
被清理，并且维护者在任何内容发布之前，都会在渲染图旁边看到全部四项。
其中没有任何内容决定文件名或地址：服务会根据名称生成地址，
保留小写字母、数字和连字符，并拒绝其他任何内容。

你的浏览器从包中读取这些框的内容（只读取其 `manifest.json`）。文件本身
只有在你按下发布时才会离开。

| | 预设 | 主题 |
|---|---|---|
| 包 | 最大 4 MB | 最大 8 MB |
| 频率 | 同一地址每小时最多五次提交，预设和主题合计 | |

## 图片不由你来提交 {#the-picture-is-not-yours-to-send}

你不能给任何一个库附上截图。服务会根据你的包渲染图片。

对于**预设**，它在应用使用的同一个沙盒文档中，根据包绘制弹窗，
在没有网络、也没有自身脚本的浏览器中进行一次，大小与应用显示的相同。它会在
预设必须处理的每种状态下绘制：普通解锁、铜色、银色和金色的稀有解锁、
100% 弹窗以及进度步骤。卡片一次显示一个，两侧各有一个箭头按钮用于
逐个切换，放大后的图片就是当前显示的那张。设计时请检查全部六种：
只在其中一种状态下看起来不错的预设，会在这里露出问题。

**主题**只是颜色和数字，所以服务器会用你的主题绘制 AW Next 界面的一个固定示例（标题栏、个人资料行、游戏库、
最近解锁列表、设置界面），并对其拍摄。这就是设置在导入之前显示的示例，大小也相同。
它每次都放在同样的四种背景渐变上，所以透明的主题不会渲染成褪色的设计，同一个文件的
两次渲染结果也一致。

示例文本是应用源代码中的常量，所以卡片不会带有你的游戏库、账号、路径或
游戏，也不会显示你没有发送的提交版本。

## 文件中包含什么 {#what-travels-in-a-file}

**`.awpreset`** 包含预设的文档和样式表、它的图片、字体和声音，以及背后的
设计器设置。不包含任何关于你机器的信息。

**`.awtheme`** 包含颜色、渐变、适应方式、效果设置和你选择的任何背景图片，
没有其他内容：没有样式表、标记或脚本。图片以字节形式、使用根据其图层生成的名称传递，
绝不是指向你图片文件夹的路径。完整列表见
[`.awtheme` 格式](../awtheme-format.md)。

**用户样式表主题无法导出。** 你放入 `%APPDATA%\Achievement Watcher Next\themes` 的 `.css`
不是 `.awtheme`，导出会拒绝它。请直接分享 `.css` 本身。

## 背景和其他素材 {#backgrounds-and-other-assets}

包内的所有内容都会重新分发给每个下载它的人，所以必须是你有权重新分发的：

- 你自己的美术作品，或采用允许这样做的许可证的内容。找到的壁纸通常两者都不是，
  购买的字体也是如此。
- 不得带有标志、水印或嵌入的文字。主题是一种外观，而不是广告位。
- 不得包含在工作场合不适合作为桌面背景的内容。

只用颜色构成的主题很受欢迎，也是最容易通过的类型。

## 署名和许可 {#credit-and-licence}

卡片上的名称就是 **署名** 框最终写的内容。它一开始是你导出时应用
记录的作者，所以通常是对的。如果你用别的名字，可以更改，或清空它，
卡片就不带名字。维护者在批准时可以添加指向你个人资料的链接。

**两个库中列出的所有内容都按
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 发布。** 提交即表示你同意这一点，
并确认这是你自己的作品，其中的一切都由你有权授予。

## 会检查什么 {#what-is-checked}

提交必须通过两层检查。

**应用自己的读取器。** 导入时运行的模块 `app/util/presetPackage.js` 和 `app/util/themePackage.js`
会验证包：清单、格式版本、最低应用版本、其中的每个
路径、文件类型、大小和入口点。库服务逐字使用这些文件，
所以在那里添加的规则会在下一次构建时应用到这里，应用会拒绝的内容
不可能被列出。

**库自己的限制**，私人导入不需要这些：

| | |
|---|---|
| 文件名 | 小写字母、数字和连字符，2 到 48 个字符，由服务根据名称生成 |
| 包 | 预设 4 MB，主题 8 MB |
| 图片 | 由服务按每种状态渲染一次，如果任何一张超出列表所提供的大小范围就会被拒绝（每张最大 500 KB） |
| 名称 | 在其库中唯一，因为两个同名条目在导入时会冲突 |

包内的任何内容在检查期间都不会被执行，网站也从不渲染包：卡片显示的是服务生成的
图片。预设只在应用中运行，使用与内置预设相同的沙盒通知窗口，
而主题无法在任何地方运行任何东西。

## 会被拒绝的内容 {#what-gets-refused}

- 他人的作品，除非对方同意且你已署名。
- 你无权重新分发的素材。
- 冒充其他事物的弹窗：系统对话框、广告、要求访问的地址。
- 嵌入背景图片的广告、标志或行动号召。
- 使文字难以辨认的配色。
- 与已列出内容近乎重复的作品。

拒绝时会保留校验和并删除字节，所以再次发送同一文件会被识别，
而不是排队两次。

## 更新或移除你的作品 {#updating-or-removing-yours}

用同样的方式发送较新的文件，并把包内的版本号调高，同时在说明中写明它取代了
较早的卡片，以便维护者撤下那一张。要移除某个条目，请
[提交 issue](https://github.com/Shirowwww/Achievement-Watcher-Next/issues/new/choose)，并
说明是哪一张卡片。

## 面板不存在时 {#when-the-panel-is-not-there}

没有库服务器在响应，页面会列出发布在它旁边的副本。库中已有的所有内容
仍然可以下载。只有提交新内容需要等待，所以请稍后再试。

让面板出现的服务由项目运营，不属于本仓库，所以
无需为它安装任何东西。

## 来自 Steam Achievement Notifier 的主题 {#themes-from-steam-achievement-notifier}

它们不会列在这里，以后也不会。

SAN 主题是人们互相直接传递的 `.san` 文件。SAN 仓库没有主题
文件夹、wiki 列表或订阅源，所以构建没有可指向的地方。这些文件属于制作它们的
人，没有获得再分发的许可，而且 SAN 仓库根本没有许可证。
把任何一个复制到这里，都等于未经许可重新发布他人的作品。

AW Next 转而读取你自己的。**设置 → 通知预设 → 导入 SAN 主题** 读取 `.san`
文件，或已解压主题的 `usertheme.json`，而 **从此电脑上的 SAN 导入** 读取
SAN 自己的设置。无论哪种方式，主题都会变成 AW Next 预设，用 SAN 自己的引擎
按 SAN 的大小绘制，并像其他预设一样导出为 `.awpreset`。迁移的内容见
[预设](presets.md#import-a-theme-from-steam-achievement-notifier)。

如果你导入了自己的主题，请导出并提交它。那样它就是你的预设，署你的名。

- [Steam Achievement Notifier](https://github.com/SteamAchievementNotifier/SteamAchievementNotifier)
