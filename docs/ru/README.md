## Где хранятся ваши данные {#where-your-data-lives}

Всё, что записывает AW Next, лежит в **`%APPDATA%\Achievement Watcher Next`** (в Linux это `~/.config/Achievement
Watcher Next`, структура та же). Пути ниже указаны относительно этой папки. При обновлении всё сохраняется,
а при первом запуске импортируется папка старого Achievement Watcher, которая при этом не изменяется.

| Что | Где |
|---|---|
| Настройки, индексы и базы данных | `cfg\` (`options.ini` - файл настроек) |
| Журналы | `logs\` |
| Созданные или импортированные вами пресеты | `presets\Users Presets\` |
| Картинки, которые пресет использует как фон | `presets\images\` |
| Добавленные вами звуки | `sounds\` |
| Сохранённые или импортированные темы | `theme-packs\` |
| Изображения для темы «Своя» | `theme-images\` |
| Тема в виде таблицы стилей, которую вы положили сами | `themes\` |
| Резервные копии достижений, в том числе сделанные перед исправлением GBE | `backups\achievements\`, `backups\gbe\` |
| Обложки и значки игр | `covers\`, `gameIcons\` |
| Скриншоты | `Pictures\Achievement Watcher Next` (или выбранная вами папка) |
| Подключённые учётные записи | `steam_session.enc`, `epic_tokens.enc`, `cfg\xbox-auth.json`, `cfg\psn-auth.json` |
| **Можно загрузить заново:** схемы, значки и редкость с платформы | `steam_cache\`, `uplay_cache\` |
| **Можно загрузить заново:** скачанные инструменты и результаты сканирования папок | `cache\` (кроме `cache\uplayR2`, где лежит предоставленная вами DLL) |
| Сохранения GBE Fork (записывает эмулятор) | `%APPDATA%\GSE Saves` |
| Сохранения классического Goldberg (то же самое) | `%APPDATA%\Goldberg SteamEmu Saves` |

**Настройки → Дополнительно → Очистить кэши** очищает две строки, которые можно загрузить заново, и ничего
больше. Ничего из `cfg\`, `presets\`, `theme-packs\`, `theme-images\`, `themes\`, `sounds\`, `covers\`,
`gameIcons\` и `backups\` не создаётся заново, поэтому скопируйте эти папки перед переустановкой.

Прежде чем сообщать о проблеме, запустите **Настройки → Дополнительно → Диагностика**, воспроизведите её один
раз, а затем удалите личные данные из журналов, которые прикладываете.

### Что уходит с этого ПК {#what-leaves-this-pc}

В AW Next нет ни аналитики, ни телеметрии, ни собственной учётной записи. Он отправляет только нужные ему
запросы и кэширует каждый ответ, чтобы библиотека работала и без сети.

| Что запрашивается | У кого | Что передаётся |
|---|---|---|
| Списки достижений, значки, глобальная редкость | Публичные точки доступа Steam, страница SteamCommunity, SteamHunters, Exophase | AppID игры и язык интерфейса |
| Обложки и логотипы | Steam CDN, SteamDB, SteamGridDB | AppID или название игры |
| Проверка и загрузка обновлений | Лента релизов GitHub | Только сам запрос |
| Инструменты исправления, когда вы запускаете исправление | Проекты GBE Fork, Steamless, API-bypass и CrakFiles | Только сам запрос |
| Ваша библиотека и разблокировки, **только если вы подключили учётную запись** | Steam, Epic, Xbox Network или PlayStation Network | Токен сеанса учётной записи; для разблокировок Steam - публичный Steam ID |
| Ваша библиотека RetroAchievements и разблокировки, **только если вы заполнили карточку учётной записи** | retroachievements.org | Ваше имя пользователя и ключ Web API, хранящиеся на этом ПК в зашифрованном виде |
| Пресеты и темы сообщества, **только если вы открываете галерею или публикуете в ней** | Служба галереи, `aw-gallery.shirow.dedyn.io` | Запрос списка; файл - только когда вы нажимаете «Опубликовать» |

Если в исполняемом файле игры есть настоящий значок 256 px, AW Next читает его из файла и использует как
логотип, не обращаясь к сети.

Этот сайт не устанавливает cookie, не ведёт аналитику и загружает шрифты и скрипты со своего же хоста.
Страницы галерей получают список из указанной выше службы галереи, а при её недоступности берут копию,
сохранённую рядом с ними.

Больше ничего не отправляется: ни ваша библиотека, ни время игры, ни папки, ни скриншоты. Необязательная
трансляция `Websocket @localhost:8082` слушает только `127.0.0.1`, поэтому читать её могут лишь программы на
этом ПК. Единственное, что вы отправляете намеренно, - пресет или тема, опубликованные в галерее (см.
[Галереи сообщества](community-galleries.md)).
