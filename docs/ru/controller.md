# Руководство по контроллеру (геймпаду)

Геймпад может управлять двумя отдельными местами: главным окном и внутриигровым оверлеем. Оба настраиваются в
**Настройки → Контроллер**.

## Два переключателя {#the-two-switches}

| Параметр | По умолчанию | Что он охватывает |
|---|---|---|
| **Управлять приложением геймпадом** | Вкл. | Главное окно AW Next: библиотека, сведения об игре, настройки и поиск. |
| **Управление внутриигровым оверлеем контроллером** | Выкл. | Внутриигровой оверлей, которым управляет фоновый отслеживатель, пока вы играете. |

Навигация по приложению - это обычный ввод в окне и ничего не стоит, поэтому она включена по умолчанию. Управление оверлеем загружает
нативный стек контроллера в фоновом отслеживателе, поэтому оно включается по желанию.

## Сочетания клавиш кратко {#shortcuts-at-a-glance}

Названия кнопок используют терминологию Xbox; приложение показывает их в выбранной вами раскладке.

<img src="../assets/img/controller-map.svg" width="700" height="422" alt="Геймпад с сочетаниями по умолчанию: LT открывает «Состояние игры», RT запускает игру, LB и RB меняют вкладку настроек, крестовина перемещает фокус, A подтверждает, B отменяет, X ищет, Y и Start открывают настройки, а также три комбинации для оверлея" loading="lazy">
</div>

| Сочетание | По умолчанию | Где |
|---|---|---|
| Открыть / закрыть оверлей | **Back + Start + LB** | В игре |
| Включить навигацию по оверлею | **LB + X** | Оверлей открыт |
| Перемещать и прокручивать оверлей | **LB + RB** (удерживать) | Оверлей открыт |
| Подтвердить | **A** | Приложение + оверлей |
| Назад / отмена | **B** | Приложение + оверлей |
| Фокус на поле поиска | **X** | Приложение + оверлей |
| Открыть настройки / параметры оверлея | **Y** | Приложение + оверлей |
| Открыть настройки | **Start** | Приложение |
| Запустить выбранную игру | **RT** | Приложение, библиотека |
| Открыть «Состояние игры» выбранной игры | **LT** | Приложение, библиотека |
| Предыдущая / следующая вкладка настроек | **LB** / **RB** | Приложение, настройки открыты |
| Прокрутить страницу | **LB** / **RB** | Приложение, настройки закрыты |

Переключение оверлея использует три кнопки, чтобы оно не сработало случайно посреди игры. Каждое сочетание оверлея
настраивается и принимает от одной до трёх кнопок.

В библиотеке стик перемещает между плитками, а **A** открывает игру, как щелчок. Два
элемента, нарисованных на плитке, соответствуют триггерам: **RT** запускает выбранную игру, а **LT** открывает
её панель «Состояние игры». Оба ничего не делают, если не выбрана плитка библиотеки.

## Параметры {#options}

- **Раскладка геймпада**: терминология для подсказок и названий кнопок. **Авто** следует подключённому геймпаду,
  если его удаётся определить; остальные варианты - **Xbox**, **PlayStation** и **Switch**.
- **Бэкенд контроллера**: **Авто** выбирает лучший доступный механизм ввода, **XInput** - самый
  совместимый, а **GameInput** подходит для новых сборок Windows.
- **Назначения**: от одной до трёх кнопок на сочетание. Сочетания могут делить кнопку (по умолчанию так и есть:
  **LB + X** и **LB + RB** используют LB), а слой ввода следит, чтобы удержание одной комбинации не
  вызывало другую. Кнопка, повторённая внутри одного назначения, считается один раз. Переключение оверлея также принимает
  кнопку **Guide**; два режима оверлея - нет, потому что браузерный API геймпада, который их
  читает, не сообщает о ней надёжно.
- **Фокусировать оверлей при открытии**: передаёт оверлею фокус клавиатуры, что ставит на паузу многие игры,
  теряющие фокус. По умолчанию выключено.
- **Отправлять Esc в игру при открытии геймпадом**: отправляет нажатие Escape в игру, находящуюся в фокусе, непосредственно
  перед открытием оверлея, так что многие игры ставятся на паузу или открывают своё меню. Это срабатывает только при
  открытии с контроллера во время запущенной игры, но никогда для горячей клавиши на клавиатуре. По умолчанию выключено.

## Окно приложения {#app-window}

При включённой навигации по приложению нажатие любой кнопки геймпада в главном окне показывает кольцо фокуса.
Крестовина или левый стик перемещают между элементами, и действуют перечисленные выше сочетания. Две подробности:

- **B** сначала выходит из текстового поля, а затем возвращается назад или отменяет, так что покинуть поле
  поиска можно без мыши.
- **LB** / **RB** переключают вкладки настроек, пока открыты настройки, и прокручивают страницу, когда они закрыты.

Движение мыши или нажатие клавиши на клавиатуре возвращает управление мыши и клавиатуре.

## Внутриигровой оверлей {#in-game-overlay}

**Back + Start + LB** открывает или закрывает оверлей поверх запущенной игры. **LB + X** затем переключает
режим навигации: крестовина или левый стик перемещает кольцо фокуса, **A** подтверждает, **B** отменяет, **X**
переводит фокус на поиск, а **Y** открывает панель параметров. Удержание **LB + RB** перемещает оверлей
левым стиком и прокручивает список правым стиком.

Небольшой значок **UI** виден в заголовке, пока навигация активна, а строка подсказок показывает ваши собственные
назначения и раскладку. Остальное об оверлее - в [руководстве по оверлею](overlay.md).

> [!IMPORTANT]
> Windows не позволяет стороннему приложению захватить контроллер монопольно, поэтому игра может по-прежнему
> получать нажатия кнопок, пока оверлей открыт. Чтобы игра встала на паузу, включите **Фокусировать оверлей
> при открытии** (большинство игр ставятся на паузу при потере фокуса) или **Отправлять Esc в игру при открытии
> геймпадом**.

## Поддерживаемые геймпады {#supported-pads}

Поддерживаются контроллеры Xbox, PlayStation DualShock 4 / DualSense и Switch Pro. Геймпады Xbox
работают через XInput; геймпады PlayStation и Switch читаются через необработанный HID, поэтому им не нужен
драйвер производителя.

## Если контроллер не обнаружен {#when-a-controller-is-not-detected}

1. Убедитесь, что включён нужный переключатель: навигация по приложению и управление оверлеем - разные вещи.
2. Явно попробуйте бэкенд **XInput**; **Авто** может выбрать GameInput в сборке, где данный геймпад
   не перечисляется.
3. Проверьте геймпад на панели игровых устройств Windows (`joy.cpl`). Если Windows его не видит, AW Next
   тоже не увидит.
4. Для сообщения об ошибке добавьте `debugLogging = true` в раздел `[controller]` файла
   `%APPDATA%\Achievement Watcher Next\cfg\options.ini` и перезапустите. Тогда фоновый отслеживатель пишет
   в журнал диагностику на уровне кнопок. Переключателя в интерфейсе нет, потому что вывод многословен; потом
   выключите это.

## В Linux {#on-linux}

В Linux AW Next читает геймпады из устройств ввода ядра, и приведённые выше сочетания работают так же. Пока
работает Steam Input, он читает только виртуальные геймпады Steam, поэтому одно нажатие не засчитывается дважды.
Steam Deck и плагин Decky описаны в разделе [Linux и Steam Deck](linux.md#steam-deck).
